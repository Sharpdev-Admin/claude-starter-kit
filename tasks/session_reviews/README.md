# session_reviews/ — un compte rendu par fin de session

`/eos` écrit ici un fichier `AAAA-MM-JJ_HH-MM_reviewed.md` par session : ce qui a été fait, ce
que Nicolas a corrigé, les leçons proposées et lesquelles ont été acceptées ou refusées.

Si Nicolas répond « plus tard » à la revue, le brouillon est sauvé en `..._pending.md` et repris
à la session suivante.

Ces fichiers sont l'historique ; les règles retenues vivent dans `../lessons.md`.
